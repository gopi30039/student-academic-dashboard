STUDENT ACADEMIC DASHBOARD – MINI PROJECT

Files:
- index.html : website structure
- style.css  : design and responsive layout
- script.js  : navigation and assignment interactions

HOW TO USE:
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview in Chrome.

HOW TO PUBLISH WITH NETLIFY:
1. Visit https://app.netlify.com/drop in Chrome.
2. Sign in or create a Netlify account.
3. Extract the ZIP on your phone/computer first.
4. Upload/drag the extracted folder (the folder containing index.html, style.css and script.js) to the Netlify Drop area.
5. Wait for deployment. Netlify will show your live website URL.
6. Copy that URL and paste it into the spreadsheet column named "website/output link".

HOW TO ADD GITHUB LINK:
1. Visit https://github.com and sign in.
2. Create a new public repository, e.g. student-academic-dashboard.
3. Choose Add file > Upload files.
4. Upload index.html, style.css, script.js and README.txt (or upload the extracted files).
5. Click Commit changes.
6. Copy the repository URL and paste it into the spreadsheet column named "GITHUB LINK".

IMPORTANT:
This is a front-end college demo with sample student details, marks, attendance and timetable. Replace the sample information with approved details before submission. It does not connect to a real college database or provide real student login/security.
